Judges ke technical sawal

1GPS ya beacon ke bina user kahan khada hai, ye kaise pata chalta hai?
  • Har jagah laga QR code page ko seedha usi spot pe kholta hai (#spot-id).
  • Bolkar: "Where am I" mein mic dabake "main 203 mein hoon" ya "OT ke bahar hoon".
  • QR na mile to paas ke board ki photo; AI padh ke jagah set karta hai.
  • Ya list mein se apni jagah chun lo.

Lagatar tracking nahi. User har mod pe "Next" dabata hai, isliye na beacon chahiye na koi hardware.

2Dijkstra kyun, A* kyun nahi?

Hospital ka graph chhota hai: ~480 nodes (250 corridor points, 194 kamre, 36 lift/seedhi). Itne chhote graph pe Dijkstra turant jawab deta hai aur sabse chhota rasta pakka deta hai. A* se yahan koi khaas fayda nahi; shehar jitne bade graph pe heap ya A* lagana aasaan hai.

3Kai floor aur lift kaise handle hote hain?
  • Lift aur seedhi graph mein "core" hain; alag floor ke same core aapas mein jude hote hain.
  • Lift ka cost 3 per floor (plus pahunchne ka 10); seedhi ka 25 per floor.
  • "Step-free" chuno to seedhi hat jaati hai; "Lift not working" chuno to lift.
4Aap kahan khade ho, uske hisaab se alag rasta kaise aata hai?

Corridor ek ghere (ring) mein hain, beech mein garden walkway aur skywalk, isliye ek jagah ke 2–3 raaste bante hain. Nephrology OPD tak:

  • Gate 3 se: garden ke raaste 132 m
  • Gate 1 se: west corridor se 162 m
  • Gate 2 se: 28 m

Is baat ka test bhi likha hua hai.

5Fire evacuation plan ki photo se map kaise banta hai?
  1. Photo ko seedha kiya jaata hai, uspe grid aur lines banti hain (Python + OpenCV).
  2. Kamron aur corridor ko trace karke site.json mein daala jaata hai.
  3. Tests check karte hain ki har kamra pahuncha ja sake aur har photo maujood ho.

Convention Building ka map isi tarah ek photo se bana. Ye abhi aadha manual hai app ke andar: abhi nahi

6AI galat jawab de ya kuch bana de to?
  • Jawab ek tay JSON format mein hi aata hai.
  • AI jo room id de, server check karta hai ki wo building mein hai; galat id null ho jaati hai.
  • AI ko rasta (lift, upar/neeche, mod) batane se mana kiya hai; wo sirf jagah aur floor batata hai. Asli rasta engine nikaalta hai.
  • Koi bhi error ya time-out ho to app apni offline samajh pe chala jaata hai.
  • Hospital ke rules (aiRules) data mein, jaise "blood chahiye" = Blood Bank 101.
7Internet ya AI na ho to?
  • Rasta, search, "kahan hoon / kahan jaana", 2D/3D map, awaaz aur bheed ka andaza sab phone pe chalte hain.
  • Test: teeno buildings mein har jagah se har jagah ke 44,838 raaste, aur har kamra apne Hindi/English naam aur number se, bina AI ke.
  • Service worker pehli baar mein app, data aur photos save karta hai; network band karke reload kiya, app chala aur rasta bana.
  • Help page pe "Offline demo" switch AI aur live counter band karke ye dikhata hai; search box ke paas "AI / Offline" ka nishaan.
8Ek hi vaakya mein "kahan hoon" aur "kahan jaana hai"?

"Main 301 mein hoon aur mujhe 202 jana hai", "301 se 202", "papa ICU mein hain unse milna hai": AI dono jagah samajhta hai. Bina AI ke offline parser bhi "hoon / jaana hai / se / from…to" aur Devanagari ank (३०१) samajhta hai. Sirf jagah batayi to pehle chuni manzil rehti hai aur rasta nayi jagah se ban jaata hai.

9Parchi (OPD slip) ki photo se rasta?

Search box mein 📄 button: parchi ki photo do, AI department / room / jaanch padhta hai aur rasta shuru. Test: 4 sample parchiyan (English, poori Hindi, X-ray jaanch, haath se likha "Paediatrics G-05"), chaaron sahi kamre pe gayi. AI ko mareez ka naam, umar, phone, registration number lautane se mana kiya hai; photo save nahi hoti.

10Bheed ho to doosra rasta? Bina internet ke bhi?

Bina internet, Wi-Fi ya Bluetooth ke koi phone ye nahi jaan sakta ki abhi kisi corridor mein kitne log hain. Isliye:

  • Offline, samay se andaza: hospital ke aam bheed wale ghante data mein (registration subah 8–1, billing 10–4, ward visiting shaam 4–7). Us waqt wo corridor "lamba" maana jaata hai.
  • Offline, logon ko baantna: do raaste lagbhag barabar hon to har phone apne fixed random number se ek chunta hai; aadhe ek raaste, aadhe doosre.
  • Online, live count: "Start navigation" pe us raaste ke har corridor point pe +1, "I have arrived"/End pe −1, button na dabaye to apne aap expire. Kisi point pe 10+ log = agle bande ko doosra rasta. 2.5 second mein jawab na aaye to offline andaza. Sirf random trip id + corridor points, koi personal data nahi.

Bluetooth phone-to-phone ginti website mein sambhav nahi (native app chahiye). Count abhi server ki memory mein hai; kai-server deploy pe Redis lagega Redis: abhi nahi

11Chalte waqt lift kharab ho ya rasta band ho to?

Navigation screen pe "रास्ते में दिक्कत?": mic se bolo ("लिफ्ट खराब है", "aage rasta band hai", "seedhi nahi chadh sakta") ya button dabao. Wahi lift (saare floors) ya wo corridor band maan kar jahan aap abhi ho wahin se naya rasta, navigation chalu rehta hai, aur app bolkar batata hai. Offline chalta hai. Test: 203 → 304 Lift A se tha; "लिफ्ट खराब है" pe Stairs 5 se 50 m ka naya rasta, phir "rasta band" pe Stairs 2 se 190 m.

12Awaaz aur bhasha kaise kaam karti hai?
  • Mic hamesha hi-IN sunta hai: Hindi, Hinglish aur Indian English teeno; bolte waqt shabd box mein dikhte hain.
  • Bolkar poocha to AI bolkar jawab deta hai, aam bol-chaal mein ("घबराइए नहीं, ब्लड बैंक पहली मंज़िल पर है…").
  • Sabse natural (neural) awaaz apne aap chuni jaati hai (jaise Google हिन्दी, Microsoft Swara); "आवाज़ बदलें" se doosri.
  • Hindi/English badlo to AI ka jawab aur bolne ki bhasha dono badal jaate hain. Phone mein Hindi awaaz na ho to English mein padhta hai aur batata hai.
13Navigation mein dikhne wali tasveer kahan se aati hai?
  • Jahan asli photo hai (Campus, Convention Building; chehre blur), wahan wahi.
  • Baaki jagah usi map se us mod ka first-person Real 3D view: corridor, darwazon pe room ke board, zameen pe neeli patti.
  • Isliye hamesha sahi aur route ke sync mein. Koi nakli ya internet se li hui photo nahi.
143D aur Real 3D mein kya farak hai?

Map pe 2D / 3D / Real buttons. 3D saaf overview hai. Real 3D mein painted diwarein, tiles, har kamre pe darwaza aur board, seedhiyan, lift ke darwaze, imaraton pe khidkiyan, ped, aasmaan aur chhaya. Real 3D mein kamre pe tap karo to uske darwaze ke saamne khade hone jaisa view. Phone pe chhaya band rehti hai taaki tez chale.

15Kharcha kitna?

Andaza, AI ke current rates pe:

  • Text sawal (Haiku 5.5): ~₹0.03–0.10 per sawal.
  • Sign ya parchi ki photo (Sonnet 5.5): ~₹0.5–1 per photo.
  • Rasta, offline search, bheed ka andaza aur 3D ka koi kharcha nahi; sab phone pe.
16Privacy?
  • Na login, na tracking, na kisi ko pehchaanne wala data.
  • API key sirf server pe; sawal aur photo store nahi hote.
  • Parchi se sirf department/room lautaya jaata hai, mareez ki details nahi.
  • Live bheed counter: sirf random trip id aur corridor points.
  • Walk-through photos mein chehre blur, location (EXIF/GPS) data hataya.
  • Mic browser ki speech service use karta hai; type karna hamesha chalta hai.
17Security?
  • Har IP ke liye rate limit (text 20/minute, photo 8/minute, live counter 30/minute).
  • Input ki jaanch: site id, image ka type, 4 MB limit, sirf asli corridor ids gine jaate hain.
  • Page pe dikhne wala har text escape hota hai, taaki HTML inject na ho.
  • "Nakli 10 log" demo button sirf RAASTA_DEMO=1 wale server pe chalta hai, public pe nahi.
  • CSP header aur kai server instance ke beech shared rate limit (Redis) abhi nahi
18AIIMS jitna bada scale kaise hoga?
  • Har building ek data file; demo hospital mein 4 block, 4 floor, 191 kamre, 4 lift, 5 seedhiyan, 3 gate.
  • 3D mein ek jaisi cheezein instancing se, isliye 1000+ furniture bhi halka; 3D tabhi load hota hai jab zarurat ho.
  • Bade deployment pe: Go server + Redis (cache, rate limit, live counter) + Kafka (anonymous analytics). Abhi ki zarurat ke liye ye bhaari hai, isliye plan mein rakha hai.
19Koi framework (React wagairah) kyun nahi?

Download chhota rehta hai aur sasta phone bhi jaldi khol leta hai. Prototype bhi aise hi bana tha.

20Accessibility?

Step-free (wheelchair) rasta, chalte waqt "seedhi nahi chadh sakte" bolkar rasta badalna, Hindi/English mein bolkar directions, mic se poochna, bade buttons, dark mode, phone ka alag layout.

21Testing kaise kiya?
  • 78 automated tests: routes, lift band / rasta band pe naya rasta, bheed ka andaza aur "10 log" rule, offline parser (Hindi/Hinglish/English), live counter API, parchi/sign/ask API (nakli AI ke saath).
  • Har jagah se har jagah (44,838 raaste) aur har kamra apne naam se, offline.
  • Teeno buildings dono bhashaon mein render (jsdom).
  • Headless Chrome mein asli AI ke saath end-to-end: likhkar, mic se, parchi upload, "Where am I"; phone screen; network band karke reload.
22Position kitni accurate hai?

Utni hi jitni QR code ki jagah. App user ko lagatar track nahi karta; har mod pe photo ya 3D view aur "Next" se user khud confirm karta hai. Phone ke sensor se kadam ginna abhi nahi

23Pehle se bana tha ya yahin banaya?

Imaandari se bataiye kab kya bana: ek single-file prototype aur build spec pehle bane the; uske upar AI coding assistant ke saath TypeScript app, AI endpoints, bada demo hospital, 3D/Real 3D, offline mode, bheed, parchi, mic aur tests banaye. Event ke rules mein jo allowed ho, usi hisaab se bataiye.
